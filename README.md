# 📄 AI Resume Analyzer

An AI-powered Resume Analyzer built with Python and Streamlit that helps job seekers evaluate how well their resume matches a job description. The application uses Natural Language Processing (NLP) techniques to calculate resume-job compatibility, identify missing skills, and provide actionable recommendations.

## 🚀 Features

* Upload resumes in PDF format
* Extract text automatically from resumes
* Compare resumes against job descriptions
* Calculate Resume Match Score
* Identify Missing Skills
* Resume Improvement Recommendations
* Analysis History Tracking
* Interactive Streamlit Dashboard
* Clean and User-Friendly Interface

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Theertha-ed/AI-Resume-Analyzer.git
```

### Navigate to Project Directory

```bash
cd AI-Resume-Analyzer
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python -m streamlit run app.py
```

## 📊 How It Works

1. Upload a resume in PDF format.
2. Paste the job description.
3. The application extracts resume content.
4. Resume and job description are analyzed using NLP techniques.
5. A compatibility score is generated.
6. Missing skills are identified.
7. Recommendations are displayed to improve the resume.
